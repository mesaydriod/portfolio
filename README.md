# Mesay Melese | Portfolio

Personal portfolio website. Plain HTML, CSS and JavaScript, no build step.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example `mesaydriod.github.io`).
2. Upload `index.html`, the `images` folder and this README.
3. Go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, then Save.
4. Your site appears at `https://mesaydriod.github.io/` after about a minute.

## Edit
- Text, links and projects: edit `index.html`.
- Photo: replace `images/mesay.jpg` (keep the same file name).
